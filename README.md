# JSON 可视化工具

一个**纯前端**的 JSON 可视化工具，直接在浏览器里格式化、压缩、转义、去转义、树形查看和搜索 JSON。所有处理都在本地浏览器完成，不上传任何数据。

在线访问：<https://json-visualizer.linranran94.workers.dev/>

## 功能

| 功能 | 说明 |
|------|------|
| 格式化 | 解析并缩进排版 JSON |
| 压缩 | 输出单行无空格 JSON |
| 去转义 | 还原转义字符串，并**递归展开嵌套 JSON 字符串**（如某字段的值本身是一段 JSON） |
| 转义 | 把当前输入转成可嵌入字符串字段的形式 |
| 尝试修复 | 容错处理常见语法错误（注释、缺引号、单引号、尾逗号、Python 风格值） |
| 树形视图 | 对象/数组可展开折叠，按类型着色 |
| 展开/折叠全部 | 一键控制树形结构 |
| 搜索 | 按 key/value 匹配并高亮，命中自动展开父节点 |
| 复制/清空 | 复制结果、清空输入输出 |
| 统计 | 输入/输出字符数、JSON 类型、节点数量 |
| 精准错误定位 | 解析失败显示**行列号 + `^` 箭头**指向具体字符 |
| 快速示例 | 一键填入各类示例，快速体验各功能 |

### 去转义的智能展开

对形如 `"content": "{\"a\":1}"` 的嵌套 JSON 字符串，去转义时会递归展开成真实对象/数组。

安全设计：

- 仅当字符串能解析成**对象或数组**时才展开
- `"000"`、`"0.4177"` 等保持字符串，不会被转成数字
- 空对象 `{}` 原样保留

### 容错修复能处理的问题

- 行注释 `//`、块注释 `/* */`
- 缺引号的键名和字符串值
- 单引号 `'x'` → 双引号 `"x"`
- 尾逗号 `{"a":1,}`
- Python 值：`True/False` → `true/false`、`None` → `null`、`NaN/Infinity` → `null`

修复后会提示改动处数与类型，供核对，不静默改数据。
